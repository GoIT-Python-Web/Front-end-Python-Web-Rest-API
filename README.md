## 📇 Contacts Manager — додаток для керування контактами

## 🛠️ Розгортання проєкту

### 📦 Встановлення залежностей

```bash
npm install
``` 
### 📦 Запуск проєкту

```bash
npm run dev
``` 

## 🚀 Про проєкт

**Contacts Manager** — це сучасний веб-застосунок для зберігання, перегляду та керування особистими чи робочими контактами. Користувачі можуть додавати нові контакти, редагувати наявні, видаляти, шукати та сортувати контакти за різними параметрами, а також експортувати або імпортувати списки контактів.

---

## 🧩 Основний функціонал

- 📱 Додавання нового контакту з іменем, телефоном, email та іншою інформацією
- ✏️ Редагування і видалення контактів
- 🔍 Пошук контактів за ім'ям, email чи номером телефону
- 📑 Фільтрація контактів за групами 
- 🔒 Аутентифікація користувачів та захист даних
